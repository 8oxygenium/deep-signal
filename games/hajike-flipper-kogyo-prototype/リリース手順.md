# リリース手順（弾け！フリッパー興業）

exe はサイト（Cloudflare Pages）には置かず、次の2か所で配布します。

| 配布先 | 役割 | URL |
|---|---|---|
| **itch.io** | ダウンロードページの**メインのボタン** | `https://hansode.itch.io/hajike-flipper-kogyo` |
| GitHub Releases | 「別のダウンロード先」（小さいリンク） | `https://github.com/8oxygenium/hajike-flipper-kogyo/releases/latest/download/Hajike-Flipper-Kogyo-Setup.exe` |

どちらのリンクも常に最新版を指すので、新しい版を上げればダウンロードページ（`games/hajike-flipper-kogyo.html`）は直さなくてよいです。

## 新しいバージョンを出すとき（まとめ）

1. `package.json` の `version` を上げる（例：1.0.1）。
2. GitHub Releases へ：このフォルダ（`games/hajike-flipper-kogyo-prototype`）で `npm run release`
   - ビルドとインストーラー作成まで行うので、`release/Hajike-Flipper-Kogyo-Setup.exe` も新しくなります。
3. itch.io へ：下の「itch.io への更新（butler）」の「毎回やること」。
4. ファイル名は変えないこと（ダウンロードリンクが固定のため）。

## GitHub Releases への公開（GitHub CLI）

1. GitHub CLI を入れる（PowerShell）：`winget install --id GitHub.cli`
   - このPCには入っています（`C:\Program Files\GitHub CLI\gh.exe`）。入れた直後で `gh` が見つからないときは、ターミナルを開き直してください（`npm run release` は標準のインストール先も探します）。
2. ログイン：`gh auth login`（GitHub.com → HTTPS → ブラウザでログイン）
   - アカウント `8oxygenium` でログインしてください。別のアカウントに置く場合は `RELEASE_OWNER=<アカウント名>` を付けて実行し、`games/hajike-flipper-kogyo.html` の「別のダウンロード先」のURLも同じアカウント名に直してください。
3. このフォルダで：`npm run release`
   - ビルド → インストーラー作成 → 公開リポジトリ `8oxygenium/hajike-flipper-kogyo` が無ければ作成 → Release `v<バージョン>` に exe をアップロード、まで自動で行います。
   - 同じバージョンで実行し直すと、その Release の exe を差し替えます。

### 手動で行う場合

1. このフォルダで `npm run dist` → `release/Hajike-Flipper-Kogyo-Setup.exe` ができる。
2. リポジトリ `hajike-flipper-kogyo` の「Releases」→「Draft a new release」→ 新しいタグ（例 `v1.0.1`）→ `Hajike-Flipper-Kogyo-Setup.exe` をドラッグ＆ドロップ →「Publish release」。

## itch.io への更新（butler）

butler は itch.io 公式のアップロード用ツールです。ブラウザでファイルを上げ直さなくても、コマンド1つで新しい版に差し替えられます。

### 初回だけ

1. butler を入れる
   - ダウンロード：`https://broth.itch.zone/butler/windows-amd64/LATEST/archive/default`（zip。itch.io のページ `https://itchio.itch.io/butler` からでも可）
   - 好きなフォルダ（例：`C:\butler`）に展開し、そのフォルダを環境変数 `Path` に追加する（Win + X →「システム」→「システムの詳細設定」→「環境変数」→ `Path` →「新規」）。
   - **ターミナルを開き直して** `butler version` で番号が出ればOK。
2. ログイン：`butler login`（ブラウザが開くので、itch.io のアカウント **hansode** で許可する）
3. 1回目の `butler push`（下の「毎回やること」）をしたら、itch.io の「Edit game」→「Uploads」を開き、**最初にブラウザから手で上げた exe を削除（または非表示）**にする。
   - butler で上げたファイルは「windows」チャンネルとして別に並ぶため、そのままだとダウンロードが2つ並びます。
   - 新しい方に「Windows」の印が付いていることも確認する（チャンネル名に `windows` を含めると自動で付きます）。

### 毎回やること（PowerShell、このフォルダで）

butler は「フォルダ」をアップロードします。インストーラーだけを入れたフォルダを作ってから送ります。

```powershell
New-Item -ItemType Directory -Force release\itch | Out-Null
Copy-Item release\Hajike-Flipper-Kogyo-Setup.exe release\itch\ -Force
butler push release\itch hansode/hajike-flipper-kogyo:windows --userversion 1.0.1
```

- `--userversion` には `package.json` の `version` と同じ番号を入れる。
- 送ったあと `butler status hansode/hajike-flipper-kogyo` で、windows チャンネルに新しい版が載ったことを確認できます。
- 2回目以降は、前回からの差分だけが送られます。
- `release` フォルダは git に入らない設定なので、`release\itch` もコミットされません。
