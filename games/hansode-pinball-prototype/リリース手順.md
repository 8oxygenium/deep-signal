# リリース手順（HANSODE PINBALL）

exe はサイト（Cloudflare Pages）には置かず、**GitHub の公開リポジトリの Releases** に置きます。
ダウンロードページのボタンは常に最新版を指しているので、Release を作れば即ダウンロードできるようになります。

- ダウンロードURL：`https://github.com/8oxygenium/hansode-pinball/releases/latest/download/HANSODE-Pinball-Setup.exe`

## いちばん簡単な方法（GitHub CLI を使う）

1. GitHub CLI を入れる（PowerShell）：`winget install --id GitHub.cli`
2. ログイン：`gh auth login`（GitHub.com → HTTPS → ブラウザでログイン）
3. このフォルダ（`games/hansode-pinball-prototype`）で：`npm run release`
   - ビルド → インストーラー作成 → 公開リポジトリ `8oxygenium/hansode-pinball` が無ければ作成 → Release `v<バージョン>` に exe をアップロード、まで自動で行います。

## 手動で行う場合

1. このフォルダで `npm run dist` → `release/HANSODE-Pinball-Setup.exe` ができる。
2. GitHub で公開リポジトリ `hansode-pinball` を作る（README 付きで作成）。
3. そのリポジトリの「Releases」→「Draft a new release」→ タグ `v1.0.0` → `HANSODE-Pinball-Setup.exe` をドラッグ＆ドロップ →「Publish release」。
   - ファイル名は変えないこと（ダウンロードリンクが固定のため）。

## 新しいバージョンを出すとき

1. `package.json` の `version` を上げる（例：1.0.1）。
2. `npm run release`（手動なら新しいタグで Release を作り、同じ名前の exe を添付）。
3. 「latest」の Release が自動で新しいものになり、サイトのボタンはそのまま最新版を指します。
