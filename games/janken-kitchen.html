じゃんけんキッチン

JANKEN KITCHEN

プレイ可能な開発版 / v0.1.4

HAPOMUの小さなジャンケン筐体。昔の駄菓子屋・アーケードゲーム風の3ボタンミニゲーム構想。

じゃんけんキッチン (JANKEN KITCHEN) v0.1.4 prototype is now playable.

PLAY PROTOTYPE

コンセプト

グー・チョキ・パーの3ボタンで勝負し、OMU COINを集めるレトロ筐体風ゲームです。

JAN... KEN... PON! のランプが光ったら勝負。勝てばコイン、負ければLIFEが減る、ちょっとだけ熱いキッチン筐体を目指します。

ゲーム案

  • GUU / CHOKI / PAA の3ボタン操作
  • JAN... KEN... PON! の演出
  • 勝つと OMU COIN が増える
  • あいこは再勝負
  • 負けるとLIFEが減る
  • 連勝ボーナス
  • 食べ物キャラやHAPOMUキャラが対戦相手として登場

キャラ案

  • オムライスさん
  • カップラーメンくん
  • ケチャップボトル
  • たまごちゃん
  • エビフライ店長
  • SIGNAL CORE ゲスト枠

操作イメージ

  • キーボード: 1 / 2 / 3
  • マウス・タッチ: 3つの大きなボタン

今後

  • v0.1.4では選んだ手を押した時点で表示し、CPUルーレット時間を少し長く調整
  • 今後はスコア、連勝、OMU COIN、称号をさらに調整予定

開発意図

昔ながらの駄菓子屋やゲームセンターにあった、3ボタンのジャンケン筐体をブラウザで再現したいという発想から生まれました。ルールを読まなくても、ボタンを押せば誰でもすぐ理解できるシンプルさを大事にしています。ボタンを押すタイミングと演出のテンポだけで勝負が決まるため、小さな子どもでもすぐに参加できることを意識しました。

現在の開発状況

v0.1.4まで版を重ね、選んだ手をその場で表示する演出と、CPUルーレットのタイミング調整を行いました。3ボタン操作、OMU COINの獲得、LIFE制、あいこ時の再勝負までは実装済みで、実際に最後まで遊べます。

既知の課題

  • 連勝ボーナスや称号システムはまだ未実装。
  • 対戦相手キャラ（オムライスさんなど）のビジュアルはまだ一部のみ。
  • 効果音・演出の強弱調整が途中。
  • キーボード操作（1 / 2 / 3キー）とボタン操作の反応タイミングの差を、今後もう少し詰めたい。

このゲームの独自性

「JAN... KEN... PON!」のランプ演出でテンポを作り、負けてもすぐ次の勝負に移れるアーケード感を重視しています。HAPOMUの食べ物キャラクターたちが対戦相手として順次登場する構成も、このゲームならではの要素です。
